# To-Do List

A simple and responsive To-Do List web application built with HTML, CSS, and JavaScript.

## Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Save tasks using browser localStorage
* Responsive and clean interface
* Add tasks by pressing Enter

## Technologies

* HTML5
* CSS3
* JavaScript
* LocalStorage API

## How to Run

1. Clone or download the repository.
2. Open index.html in a web browser.
3. Start adding tasks.

This project was created as a small demonstration of basic front-end web development skills and JavaScript DOM manipulation.
